# Azure AI Help Desk Assistant

## Project Overview

This project demonstrates an AI-powered IT Help Desk Assistant built using Microsoft Azure AI Foundry, Azure OpenAI, and Retrieval-Augmented Generation (RAG).

The assistant uses uploaded enterprise support documentation to answer common IT support questions related to:

* Password resets
* VPN setup
* Wi-Fi troubleshooting
* Active Directory account unlocks
* Outlook troubleshooting
* Printer troubleshooting

## Technologies Used

* Microsoft Azure AI Foundry
* Azure OpenAI
* Azure AI Search
* Retrieval-Augmented Generation (RAG)
* Vector Search
* Prompt Engineering

## Features

* AI-powered troubleshooting assistant
* Document-based contextual responses
* Enterprise-style knowledge retrieval
* Prompt customization
* Chat Playground testing

## Skills Demonstrated

* Azure AI deployment
* Cloud AI architecture
* AI Search indexing
* Prompt engineering
* Knowledge base integration
* RAG pipeline configuration

## Architecture

User → Azure AI Foundry → Azure OpenAI → Azure AI Search → Uploaded Support Documents
