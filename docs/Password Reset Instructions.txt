# Password Reset Instructions

1. Press:

   * CTRL + ALT + DELETE

2. Select:

   * Change Password

3. Enter:

   * Current password
   * New password
   * Confirm new password

4. Password Requirements:

   * At least 12 characters
   * One uppercase letter
   * One number
   * One special character

5. Click:

   * Submit

6. Lock and unlock your computer to verify the new password works.

7. If password reset fails:

   * Contact the IT Help Desk.
